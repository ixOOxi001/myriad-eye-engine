만안엔진 정직성체커 확장프로그램 설치 방법 (크롬 / 코멧 공통, 크로미움 기반 브라우저면 동일)

1. 주소창에 chrome://extensions 입력 후 이동 (코멧이면 comet://extensions)
2. 오른쪽 위 "개발자 모드" 스위치 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 버튼 클릭
4. 이 "정직성체커_확장프로그램" 폴더를 선택
5. 툴바에 아이콘이 새로 생김 — 끝, 다시 설치할 필요 없음
   * 만약 툴바에 안 보이면, 주소창 오른쪽 퍼즐 모양 아이콘(확장 프로그램 목록)을
     눌러서 정직성체커를 찾은 뒤 옆의 압정 모양을 눌러 고정해두면 편함

사용법 — 수동 전송 (기존 기능)
※ v1.1부터 툴바 아이콘 좌클릭은 팝업(감시 설정 창)을 엽니다. 예전처럼 "클릭 한 번
   = 즉시 전송"을 하려면 아래 방법 중 하나를 쓰세요.
1. run_honesty_checker.vbs 먼저 켜두기 (로컬서버 켜져 있어야 전송됨)
2. AI 채팅창에서 아무것도 선택 안 하고 바로(또는 [만증] 포함된 답변 텍스트만
   드래그로 선택 후) 아래 둘 중 하나:
   a) 툴바의 정직성체커 아이콘을 "우클릭" → "정직성체커로 전송" 메뉴 클릭
   b) 아이콘 좌클릭으로 팝업을 연 뒤 "지금 선택 텍스트 전송" 버튼 클릭
3. 전송 성공/실패 여부는 (a) 아이콘 좌측 상단 배지(초록 OK / 빨강 X)로, (b) 팝업
   안의 상태 문구로 확인 가능. 성공 시 정직성체커 탭에서 2초 내 자동 분석.

사용법 — 실시간 감시 모드 (v1.1 신규)
1. Verdent(verdent.ai), Gemini(gemini.google.com), GenSpark(genspark.ai) 채팅
   페이지를 열어두면 자동으로 감시가 시작됩니다(기본값: 켜짐).
2. 새 AI 응답이 완성될 때(스트리밍 멈추고 약 1.5초 후) [만반][만증] 태그가 둘 다
   없으면 화면 우측 상단에 빨간 경고 배너가 5~8초간 떴다가 자동으로 사라집니다.
   (배너는 알림용이며, 채팅창에 자동으로 아무 것도 입력하지 않습니다.)
3. 감시를 끄고 싶으면 툴바 아이콘 좌클릭 → 팝업에서 "실시간 감시 모드" 토글을 끄면
   됩니다(설정은 저장되어 다음에도 유지됨).
4. 주의: 새 대화창을 막 열었을 때 첫 번째로 안정화되는 내용은 "이미 있던 내용"으로
   간주해 경고 없이 기준선으로만 기록합니다(오탐 방지) — 그 다음부터 실제 새 응답을
   감시합니다.

주의 — 확장이 안 먹히는 사이트
퍼플렉시티(perplexity.ai)와 클로드(claude.ai) 등 일부 사이트는 자체 보안 정책으로
확장프로그램이 페이지 내용을 못 읽게 막아둘 수 있음. 이런 곳에서 아이콘 클릭이
계속 안 되거나 빈 결과만 나오면, 대신 정직성체커 페이지의 "북마클릿" 방식으로
전환할 것 (텍스트 드래그 → 즐겨찾기의 북마클릿 클릭).
